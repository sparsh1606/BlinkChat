# BlinkChat

BlinkChat is a real-time chat application built using the MERN stack with Socket.io support. It enables seamless communication through instant messaging.

## Features

- Real-time messaging with Socket.io  
- One-to-one chat support  
- User authentication (JWT-based)  
- Online/offline status indicators  
- Upload and change profile picture

## Tech Stack

- Frontend: React.js  
- Backend: Node.js, Express.js  
- Database: MongoDB  
- Real-time: Socket.io  

## Setup Instructions

### 1️. Clone the repository

```
git clone https://github.com/sparsh1606/BlinkChat.git
cd task-manager
```

---

### 2️. Backend Setup

```
cd Backend
npm install
node app.js
```


---

### 3️. Frontend Setup

```
cd Frontend
npm install
npm run dev
```
